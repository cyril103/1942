# Cumulus

Original density-field volume atlas built in Blender 4.5.4 with `blender/clouds/build_clouds.py`. The source scene and raw render are kept in `blender/clouds/`.

The shipped `cumulus-refined-atlas.png` is an artistic refinement of that render produced by the built-in image_gen tool on 6 October 2026. Its original RGBA pixels are retained. No third-party cloud photograph or texture was downloaded. Mipmaps and alpha-border treatment are handled by Godot's importer.

## Exact refinement prompt

Use case: style-transfer. Asset type: high-end real-time game cloud impostor atlas, RGBA with real alpha. Input is an editable reference atlas baked from Blender volumetric cloud fields. Preserve its exact square 2x2 grid and four isolated clouds centered in each cell, with generous transparent padding. Replace the overly smooth flat-grey shading with convincing photorealistic sunlit CUMULUS VOLUME seen from DIRECTLY ABOVE, orthographic aerial top-down. Each bank consists of many differently sized billowing towers and smaller fractal lobes: brilliant soft ivory lit upper-left ridges, readable silver-blue occlusion in valleys, neutral pale-grey shaded flanks, varied optically dense interiors, very fine diaphanous feathered vapor edges gradually becoming fully transparent. Strong but natural sculptural depth, like actual cumulus photographed from an aircraft far above. Four visibly different silhouettes: broad irregular cumulus cluster top left, elongated broken cloud bank top right, two merging cumulus masses with a vapor bridge bottom left, sparse asymmetric bank with small satellite wisps bottom right. Occupy middle 75% of each exact quadrant; do not touch cell boundaries. No ground or ocean or sky behind them, no horizon, no perspective side-view, no flat vector cloud icons, no cotton-ball outlines, no dark outline, no drop shadow on the transparent background, no checkerboard, no text, no grid lines. Real alpha transparency must be preserved and thin cloud edges must be semitransparent. The image will be rendered on small planes under airplanes in a WWII shmup, so the light-and-shadow billows must remain readable at reduced size.
